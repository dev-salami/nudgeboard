# Fonts

This app self-hosts **Instrument Sans**, a geometric/grotesk face under the SIL Open Font License 1.1. The official license is in `OFL.txt`. Files come from the Google Fonts `ofl/instrumentsans` tree.

Degular Display is a commercial font and is not included. Cabinet Grotesk was considered as a lookalike, but the official Fontshare/ITF distribution uses ITF FFL 2.0, which restricts repository redistribution, so it is not bundled here.
